## KEY LEARNINGS FROM THIS TEST

### Process Issues Discovered:

1. **Command notation ambiguity**: When using `(imp)` in quotes with 2nd person, both `you(referent)` AND `(imp)` creates redundancy. Need clarification on standard.

2. **Quote continuation**: After bracketing first sentence `['...']`, how do remaining sentences work? Are they still part of quote or separate? Current approach assumes still in quote but unbracketed.

3. **Compound words**: "family-redeemer", "guardian-redeemer" - these L2+ compounds may need:
   - Pairing: "family-redeemer/kinsman"
   - OR explication: "family member [who redeems]"
   - Need ontology check

4. **Sentence splitting in quotes**: Breaking up long quote into multiple sentences for clarity may alter the quote structure. Unclear if this is acceptable or if should keep original sentence boundaries.

5. **Euphemisms vs explicit**: "slept with" is understood but unclear if TBTA requires more explicit "had sex with" for cross-cultural clarity.
