### Root Cause Analysis:

**The §3 pronoun rule is AMBIGUOUS**. The skill file says:
- "❌ Third person pronouns (he/she/they) — resolve to nouns"
- "✅ After first occurrence: can use natural pronouns"

This seems contradictory! The reference encodings show that **third-person pronouns are NEVER used** - always use full nouns. The "after first occurrence" rule appears to apply only to first/second person pronouns maintaining their pronoun form after marking.

**Recommendation**: Clarify §3 to explicitly state:
- "Third-person pronouns (he/she/they/it/him/her) → ALWAYS use full nouns, even after first mention"
- "First/second person pronouns (I/we/you) → Mark on first use I(speaker), then can continue as 'I'"
