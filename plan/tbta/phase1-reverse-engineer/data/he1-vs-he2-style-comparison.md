# TBTA Transformation Style Comparison: He1 vs He2

**He1 (Hebrew1)**: Old Testament - Ruth (more natural)
**He2 (Hebrew2)**: New Testament - Matthew (stricter)

---

## Executive Summary

He2 (Matthew/NT) is systematically **more explicit and technical** than He1 (Ruth/OT), with the most striking difference being the introduction of **underscore annotation markers** that are completely absent in He1.

## Key Stylistic Differences

### 1. **Underscore Annotations** (MAJOR DIFFERENCE)

**He1 (Ruth)**: ❌ **NO underscore annotations**
```
Elimelech (title) and Naomi move from Bethlehem to Moab. [When judges
were ruling Israel] many people [who were living in Israel] did not have
enough food.
```

**He2 (Matthew)**: ✅ **EXTENSIVE underscore annotations**
```
Jesus was born in Bethlehem named the town _implicit in Judea named the
region/province _implicit [when king Herod ruled the people _implicit of
Judea]. People (implicit-background) called that Herod the great Herod.
```

**Underscore markers in He2:**
- `_implicit` - implicitly understood information
- `_implicitActiveAgent` - passive voice with implied agent
- `_implicitType` - implicit type/category
- `_implicitNecessary` - necessarily implied information
- `_frameInferable` - inferable from semantic frame
- `_descriptive` - descriptive/explanatory addition
- `_generic` - generic reference

**Impact**: He2 is far more **technically explicit** about what information is implicit vs explicit in the source text.

---

### 2. **Passive Voice & Agent Specification**

**He1 (Ruth)**: Accepts implicit agents naturally
```
I(Ruth) will be buried at that place by people.
```

**He2 (Matthew)**: Explicitly marks passive voice agents
```
People [who have a poor spirit] are blessed by God _implicitActiveAgent.

For [just-like you(people) judge other people _implicit] you(person) will
be judged by God _implicitActiveAgent.
```

**Pattern**: He2 systematically marks when God or other agents are performing actions in the passive voice, even when implicit in the source.

---

### 3. **Sentence Structure Complexity**

**He1 (Ruth)**: Moderate complexity, accepts natural repetition
```
Naomi's sons grew up. And Naomi's sons became men. Then these sons married
women [that were from Moab]. One son married a woman named Orpah. The other
son married a woman named Ruth.
```

**He2 (Matthew)**: Slightly more complex with nested structures
```
[When Jesus saw the crowds [(implicit-situational) that were following
Jesus],] Jesus go-up the side of a mountain. And Jesus sit-down. Jesus's
disciples came to Jesus.
```

**Pattern**: He2 has 10.2% more bracketed clauses and uses more embedded annotations within brackets.

---

### 4. **Pronoun Usage**

Both styles heavily annotate pronouns, but with subtle differences:

**He1 (Ruth)**: Simpler pronoun references, accepts repetition
```
I(Naomi) hope [that Yahweh will give peace to you(daughters in law)
[by giving new husbands to you(daughters in law)]].
```

**He2 (Matthew)**: More generic pronoun annotations
```
So [whenever you(person) give money or other things to poor people,]
you(person) (imp) do not act [just-like the hypocrites act].
```

**Pattern**: He2 uses more generic references like `you(person)` vs He1's specific `you(daughters in law)`.

---

### 5. **Vocabulary & Style Markers**

**He1 (Ruth)**: Minimal meta-markers
```
Naomi said to Ruth, ["Orpah will return to Orpah's people and to Orpah's
gods]. You(Ruth) should also return to your(Ruth's) people."
```

**He2 (Matthew)**: Heavy use of style markers
```
(title) Jesus teach-how people [people to pray]. (paragraph) Similarly,
_implicit [whenever you(people) pray,] you(people) (imp) do not act
[just-like the hypocrites act].
```

**Additional He2 markers:**
- `(title)` - section headings
- `(paragraph)` - paragraph breaks
- `(literal)` / `(dynamic)` - translation strategy labels
- `(rhetorical)` - question type markers
- `(implicit-background)` - background information markers
- `(implicit-situational)` - situationally implicit information

---

### 6. **Bracket Usage for Clause Segmentation**

**He1 (Ruth)**: Average 3.33 brackets per verse
```
You(Ruth) (imp) stay at this place tonight. In the morning I(Boaz) will
talk to that man. [If that man wants [to be your(Ruth's) kinsman-redeemer]]
I(Boaz) will permit [that man to be your(Ruth's) kinsman-redeemer].
```

**He2 (Matthew)**: Average 3.67 brackets per verse (+10%)
```
But [whenever you(person) give money or other things to poor people,]
you(person) (imp) do not let [your(person's) left hand know the thing
[that your(person's) right hand is doing]].
```

**Pattern**: He2 has slightly more clause segmentation, but the difference is modest (10%).

---

## Summary: What Makes He1 "More Natural" vs He2 "More Strict"

### He1 (Ruth/OT) - "Natural" characteristics:
1. ✅ **No technical annotation markers** (_implicit, _implicitActiveAgent, etc.)
2. ✅ **Accepts implicit information** without labeling it
3. ✅ **Simpler pronoun references** tied to specific characters
4. ✅ **Fewer meta-markers** (title, paragraph, literal/dynamic)
5. ✅ **More conversational flow** with natural repetition
6. ✅ **Less technical precision** about implicit/explicit boundaries

### He2 (Matthew/NT) - "Strict" characteristics:
1. ✅ **Extensive underscore annotations** marking implicit information
2. ✅ **Explicit agent specification** in passive constructions
3. ✅ **More generic pronoun references** (person, people)
4. ✅ **Heavy use of style markers** (title, paragraph, literal/dynamic)
5. ✅ **More technical precision** about what's implicit vs explicit
6. ✅ **Stricter semantic categorization** with type markers

## Parallel Examples

### Example 1: Simple Narrative

**He1 (Ruth 1:4)**
```
Naomi's sons grew up. And Naomi's sons became men. Then these sons married
women [that were from Moab]. One son married a woman named Orpah. The other
son married a woman named Ruth.
```

**He2 (Matthew 5:1)**
```
(title) Jesus teaches/preach about God's laws to people on a mountain.
(paragraph) [When Jesus saw the crowds [(implicit-situational) that were
following Jesus],] Jesus go-up the side of a mountain. And Jesus sit-down.
Jesus's disciples came to Jesus.
```

**Difference**: He2 adds (title), (paragraph), and (implicit-situational) markers.

---

### Example 2: Passive Voice

**He1 (Ruth 1:17)**
```
I(Ruth) will be buried at that place by people.
```

**He2 (Matthew 5:3)**
```
People [who have a poor spirit] are blessed by God _implicitActiveAgent.
```

**Difference**: He2 explicitly marks that God is the implicit agent.

---

### Example 3: Implicit Information

**He1 (Ruth 1:6)**
```
[while Naomi was living in Moab] a person told Naomi [that God was caring
for God's people in Bethlehem]. God had given food to those people.
```

**He2 (Matthew 2:1)**
```
Jesus was born in Bethlehem named the town _implicit in Judea named the
region/province _implicit [when king Herod ruled the people _implicit of Judea].
```

**Difference**: He2 explicitly marks every implicit piece of information with `_implicit`.

---

### Example 4: Translation Strategy

**He1 (Ruth 1:9)** - No strategy markers
```
I(Naomi) hope [that Yahweh will give peace to you(daughters in law)
[by giving new husbands to you(daughters in law)]].
```

**He2 (Matthew 5:3)** - Explicit literal/dynamic markers
```
["(literal) People [who have a poor spirit] are blessed by God _implicitActiveAgent].
["(dynamic) People [who know [those people need God]] are blessed by God _implicitActiveAgent].
```

**Difference**: He2 provides both literal and dynamic renderings with explicit labels.

---

### Example 5: Complex Instructions

**He1 (Ruth 3:13)** - 11 brackets, 21 pronoun annotations
```
You(Ruth) (imp) stay at this place tonight. In the morning I(Boaz) will talk
to that man. [If that man wants [to be your(Ruth's) kinsman-redeemer]] I(Boaz)
will permit [that man to be your(Ruth's) kinsman-redeemer]. [But if that man
does not want [to be your(Ruth's) kinsman-redeemer]] I(Boaz) will be your(Ruth's)
kinsman-redeemer. I(Boaz) swear to Yahweh [that I(Boaz) will be your(Ruth's)
kinsman-redeemer]." So Ruth lay down at Boaz's feet until the early morning.
```

**He2 (Matthew 6:3)** - 6 brackets, but more annotation types
```
(literal) But [whenever you(person) give money or other things to poor people,]
you(person) (imp) do not let [your(person's) left hand know the thing [that
your(person's) right hand is doing]]. (dynamic) But [whenever you(person) give
money or other things to poor people,] you(person) (imp) do not let [people see
[you(person) are doing that thing]].
```

**Difference**: He2 provides both literal and dynamic versions in same verse with explicit labels.

---

## Conclusion

**He1 (Ruth/OT) is "more natural"** because:
- It presents transformed text without heavy technical annotation
- It doesn't explicitly mark implicit information
- It accepts natural repetition and conversational flow

**He2 (Matthew/NT) is "more strict"** because:
- It systematically marks implicit vs explicit information with underscores
- It explicitly identifies passive voice agents
- It provides multiple translation strategy versions (literal/dynamic)
- It uses more meta-markers to categorize discourse types
- It aims for technical precision in representing semantic structure

The shift from He1 to He2 represents a move toward **greater technical explicitness and semantic precision** in the TBTA transformation process.
