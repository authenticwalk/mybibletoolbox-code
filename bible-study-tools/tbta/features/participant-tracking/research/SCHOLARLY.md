# Scholarly Research: Participant Tracking

## Executive Summary

Participant tracking (also called participant reference or reference tracking) is the linguistic system by which languages introduce, maintain, and reactivate references to discourse participants (characters, entities) throughout a narrative or conversation. Research reveals significant cross-linguistic variation: some languages require explicit noun phrases, others use rich pronoun systems, and still others employ zero anaphora (null subjects). Key typological features include switch-reference marking, obviation systems, pro-drop parameters, and discourse-based reference hierarchies.

**Theological Challenges**: Participant ambiguity in Biblical texts can create translation difficulties, particularly in passages involving multiple third-person referents (e.g., Acts 15-16 Silas/Paul ambiguity, Genesis 1:26 plural "us" interpretation). Translators must balance source-language participant tracking conventions with target-language requirements while maintaining theological accuracy.

**Measurement Methods**: Quantitative approaches include Givón's referential distance (RD), topic persistence (TP), and potential interference metrics; Ariel's accessibility hierarchy; and Gundel-Hedberg-Zacharski's cognitive status framework. These methods correlate linguistic form (full NP > demonstrative > pronoun > zero) with cognitive accessibility.

### Comrie, B. (1999). Reference-tracking: Description and explanation

**Publication**: Sprachtypologie und Universalienforschung 52(3/4): 335-346
**URL**: https://www.semanticscholar.org/paper/Reference-tracking:-description-and-explanation-Comrie/878e516bdfc8953e84982d5840e54fbfcab211a3
**Citation Code**: {comrie-1999-reference-tracking}

**Key Findings**:
- Two principles for reference-tracking universals:
  1. **Local Domain Principle**: Coreference MORE likely to be marked than non-coreference within single predicate arguments (cognitive basis)
  2. **Extended Domain Principle**: Non-coreference MORE likely to be marked than coreference across clause boundaries (discourse basis)
- Explains why languages use explicit marking in local contexts but allow zero anaphora for continuous topics in extended discourse
- Functional rather than formal explanation

**Relevance**: Explains the paradox of why some contexts require explicit marking while others allow zero forms. Critical for understanding Biblical Hebrew's participant tracking patterns.

## 3. Typological Reference Systems

### Switch-Reference Systems

**Sources**:
- Haiman, J., & Munro, P. (Eds.). (1983). *Switch Reference and Universal Grammar*. John Benjamins (Typological Studies in Language, Vol. 2)
- [Cambridge Handbook of Linguistic Typology - Chapter on Switch-Reference](https://www.cambridge.org/core/books/abs/cambridge-handbook-of-linguistic-typology/typology-of-switch-reference/1EE1701F893BF876662F090D2C911B9E)

**URL**: https://benjamins.com/catalog/tsl.2
**Citation Code**: {haiman-munro-1983-switch-reference}

**Key Findings**:
- Switch-reference (SR) marks whether subjects in adjacent clauses are coreferential
- Basic distinction: Same Subject (SS) vs. Different Subject (DS)
- Found in: North America, South America, Australia, Papua New Guinea, South Pacific
- Geographical clustering suggests areal diffusion
- Typologies developed for North American, Australian, and New Guinean systems

**Relevance**: Some Bible translation languages (especially Papua New Guinea) require switch-reference marking. Understanding SR helps predict when target languages need explicit participant marking.

### Obviation in Algonquian Languages

**Key Sources**:
- Culy, C. (1994). Aspects of logophoric marking. *Linguistics* 32(6): 1055-94
- Culy, C. (1997). Logophoric pronouns and point of view. *Linguistics* 35(5): 845-59

**URL**: https://en.wikipedia.org/wiki/Obviative
**Citation Code**: {culy-1994-obviation} / {culy-1997-logophoric}

**Key Findings**:
- Obviation marks third-person referent salience: proximate (most salient) vs. obviative (less salient)
- At most one proximate referent per clause; all others must be obviative
- Distinguishes 'pure' logophoric systems (African) from mixed systems (reflexive extension)
- Proximate nouns assumed to be agents; obviative nouns don't trigger strong commitments
- Operates at syntactic and discourse levels

**Relevance**: Some indigenous translation languages use obviation-like systems. Understanding prominence hierarchies helps predict which participant will be treated as primary vs. secondary.

### Pro-Drop Parameter and Null Subjects

**Key Sources**:
- Chomsky, N. (1981). *Lectures on Government and Binding*
- Rizzi, L. (1986). Null objects in Italian and the theory of *pro*

**URL**: https://en.wikipedia.org/wiki/Pro-drop_language
**Citation Code**: {chomsky-1981-pro-drop} / {rizzi-1986-null-objects}

**Key Findings**:
- Pro-drop parameter: can independent clause lack explicit subject?
- Typically requires rich verbal inflection (person/number/gender agreement)
- **Full pro-drop languages**: Arabic, Greek, Hebrew, Italian, Japanese, Korean, Persian, Slavic, Spanish, Tamil, Turkish
- **Non-pro-drop**: English, French, German
- **Partial pro-drop**: Brazilian Portuguese (vs. European Portuguese)
- Subcategories: topic (discourse) pro-drop, partial NSL, consistent NSL

**Relevance**: Biblical Hebrew and Greek are pro-drop languages. English translations must add explicit subjects. Target languages vary in whether pronouns are required or optional.

## 4. Cognitive and Psycholinguistic Frameworks

### Grosz, B. J., Joshi, A. K., & Weinstein, S. (1995). Centering: A Framework for Modeling the Local Coherence of Discourse

**Publication**: *Computational Linguistics* 21(2): 203-225
**URL**: https://aclanthology.org/J95-2003/
**Citation Code**: {grosz-joshi-weinstein-1995-centering}

**Key Findings**:
- **Backward-looking center (Cb)**: Entity being talked about (current focus)
- **Forward-looking centers (Cf)**: Candidate referents for next utterance
- Discourse coherence established by Cb continuity across utterances
- Predicts pronoun vs. full NP choice based on focus continuity
- Two levels of focusing: global (overall discourse) and immediate (local context)

**Relevance**: Centering theory predicts when Biblical texts will use pronouns vs. explicit nouns. Cb shifts signal discourse boundaries (new episodes, participants).

### Ariel, M. (1990). *Accessing Noun-Phrase Antecedents*

**Publisher**: Routledge
**URL**: https://www.cambridge.org/core/journals/journal-of-linguistics/article/abs/referring-and-accessibility/6178AFEFCBA440E3D77D39A400AFF27A
**Citation Code**: {ariel-1990-accessibility}

**Key Findings**:
- **Accessibility Marking Scale** (low to high accessibility):
  - Full name > long definite description > short definite description > last name > first name > distal demonstrative > proximate demonstrative > NP > stressed pronoun > unstressed pronoun > cliticized pronoun > **zero**
- Three universal principles: Informativity, Rigidity, Attenuation
- More informative, less ambiguous, longer forms retrieve less accessible referents
- Shorter forms (pronouns, zero) for highly accessible referents

**Relevance**: Explains form selection in Biblical texts. When Hebrew uses zero anaphora vs. pronoun vs. full NP correlates with referent accessibility in discourse.

### Demonstratives and Spatial Distance

**Key Source**: Diessel, H. (1999). *Demonstratives: Form, Function, and Grammaticalization*

**Publisher**: John Benjamins
**URL**: https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2020.555265/full
**Citation Code**: {diessel-1999-demonstratives}

**Key Findings**:
- Proximal/distal distinction may be universal
- **Distance-oriented systems**: Location relative to speaker only
- **Person-oriented systems**: Location relative to speaker AND hearer
- Three-term systems: proximal, medial, distal (e.g., Irish)
- Japanese: speaker-proximal, hearer-proximal, distal from both
- Beyond distance: visible/out-of-sight, elevation, direction (upriver/downriver, coast)

**Relevance**: Biblical demonstratives ("this one" vs. "that one") used for participant tracking. Cross-linguistic variation in demonstrative systems affects translation of referential forms.

## Executive Summary: Top 10 Findings

### 1. **Participant Tracking is Scalar, Not Binary**
Languages don't simply "have" or "lack" participant tracking—they employ graded systems (Givón 1983). Referring expressions exist on a continuum: full name > definite description > demonstrative > pronoun > zero anaphora. Form selection correlates with cognitive accessibility (Ariel 1990).

### 2. **Two Universal Principles Govern Reference-Tracking**
Comrie (1999) identifies: (1) **Local Domain**: Coreference MORE marked within single predicate; (2) **Extended Domain**: Non-coreference MORE marked across clauses. This explains why zero anaphora works for continuous topics but explicit marking needed when switching participants.

### 3. **Biblical Hebrew and Greek Are Pro-Drop Languages**
Both source languages allow zero subjects when participant is recoverable from context. English (non-pro-drop) requires explicit pronouns, forcing translators to explicate what source texts leave implicit. This creates translation challenges.

### 4. **Quantitative Measures Exist for Topic Continuity**
Givón's methodology provides three metrics: **Referential Distance** (RD) = how many clauses since last mention; **Topic Persistence** (TP) = how many clauses participant continues; **Potential Interference** = competing referents. These predict referring expression choice.

### 5. **Switch-Reference Systems Mark Participant Continuity**
Hundreds of languages (especially Papua New Guinea, Americas, Australia) grammatically mark whether clauses share same subject (SS) or different subject (DS). Bible translators working in these languages must identify participant continuity at every clause boundary.

### 6. **Cognitive Status ≠ Accessibility**
Gundel-Hedberg-Zacharski (1993) demonstrate cognitive status is NOT equivalent to simple accessibility/salience. Six distinct statuses (in focus, activated, familiar, uniquely identifiable, referential, type-identifiable) correspond to different referring expressions. Translation must match cognitive status, not just semantic content.

### 7. **Coherence Relations Drive Pronoun Interpretation**
Kehler-Rohde (2008) show pronoun resolution depends on discourse coherence relations (cause-effect, elaboration, contrast). Different relations create different referential expectations. Ambiguous pronouns in source texts may resolve differently in target languages with different coherence marking.

### 8. **Topic-Prominent vs. Subject-Prominent Languages**
Chinese/Japanese (topic-prominent) organize participant tracking fundamentally differently than English (subject-prominent). Topic chains allow extensive zero anaphora in Asian languages where English requires explicit pronouns. Translation cannot be word-for-word.

### 9. **Animacy Hierarchy Affects Participant Tracking**
Silverstein (1976): 1st/2nd person > 3rd human > animate > inanimate > abstract. Higher animacy participants tracked more carefully, receive more explicit marking. Biblical texts prioritize human participants; inanimate objects often tracked minimally or not at all.

### 10. **Theological Passages Require Precise Participant Reference**
Genesis 1:26 ("Let us make mankind"): Plural participant ambiguity affects Trinity doctrine. Languages with trial number can explicitly encode Trinity (exactly 3); dual number systems must avoid dual (implies only 2, heretical). Participant tracking has doctrinal implications in key passages.

## Implications for TBTA Algorithm Development

1. **Multi-dimensional Analysis Required**: Cannot rely on single metric (distance, persistence, interference must all be considered)

2. **Source Language Modeling**: Must account for Hebrew/Greek pro-drop patterns; what's "explicit" vs. "implicit" differs from English intuitions

3. **Target Language Variation**: Algorithm must provide multiple analyses for different target language types (pro-drop vs. non-pro-drop; switch-reference vs. pronoun systems; topic-prominent vs. subject-prominent)

4. **Cognitive Status Encoding**: Track not just "is this participant mentioned" but cognitive status level (in focus, activated, familiar, etc.)

5. **Coherence Relation Integration**: Participant tracking interacts with discourse coherence structure; cannot analyze in isolation

6. **Animacy Classification**: Participants need animacy tagging (divine, human, animal, inanimate, abstract) as this affects reference form predictions

7. **Theological Flagging**: Key passages (Trinity references, Christological texts) need special handling; participant ambiguity has doctrinal consequences

8. **Training Data from Multiple Languages**: Givón's cross-linguistic methodology suggests algorithm training should include non-English data (especially Biblical Hebrew corpus analysis)

9. **Zero Anaphora Detection**: Must identify where source texts use zero anaphora vs. overt pronouns; this signals discourse function differences

10. **Translation Database Design**: Stage 4 translation database should include languages from different typological categories: pro-drop (Spanish, Greek), non-pro-drop (English, French), topic-prominent (Chinese, Japanese), switch-reference (Papua New Guinea languages)
