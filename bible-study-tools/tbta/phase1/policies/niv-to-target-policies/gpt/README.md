## NIV → Targets Intermediary Policy (GPT)

**Purpose**: Define a compact, generic policy for converting **NIV** (and similar dynamic equivalents) into the **targets.tabitha.bible** intermediary English used for *Unchurched Adults*, optimized for further translation into any language.

- **Scope**: Narrative OT/NT passages (prototype: **Ruth 1**), but rules are designed to generalize across Scripture.
- **Foundation**: This policy **extends** existing TBTA Phase 1 SKILL policies:
  - `bible-study-tools/tbta/phase1/policies/SKILL.md`
  - `.../rules/pronouns.md`, `vocabulary.md`, `clauses.md`, `determiners.md`, `quotes.md`, `implicit.md`, `special.md`
- **Audience**: Agents starting from **NIV** who must output text that looks like the **Unchurched Adults** version in `targets.tabitha.bible`.

Files in this folder:

- `process.md` — ordered **step-by-step pipeline** (what to do first, next, last)
- `rules.md` — **prioritized rule list** (R1, R2, …) with brief explanations and SKILL references

Keep these files **short and generic**. For verse-specific quirks or experiments, use `/plan` or TBTA learnings, not this folder.
