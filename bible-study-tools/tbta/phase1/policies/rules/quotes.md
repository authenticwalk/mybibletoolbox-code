# Quotes (Checklist §10)

## Basic Structure

Quotes always introduced with speaker + verb:
```
John said, ["I(John) love you(Mary)"].
```

## Single Sentence Quote
Bracket around entire quote (it's patient clause of "say"):
```
Richard said, ["I(Richard) love you(Mary)"].
```

## Multi-Sentence Quote
Bracket only around FIRST sentence:
```
Richard said, ["I(Richard) love you(Mary)]. So I(Richard) want [to hold your(Mary's) hand]."
```

Why? First sentence is patient clause. Rest continues the quote but isn't a separate patient clause.

## Implicit Speaker/Verb
If not in literal text:
```
John _implicitNecessary said _implicitNecessary, ["..."]
```

In He1:
```
<John> <said>, "..."
```

## Multi-Paragraph Quotes
- One open quote at very beginning
- One close quote at very end
- ❌ Don't put open quote at start of each paragraph (unlike natural English)

## Indented Text (NIV)
- NIV sometimes uses indentation for quotes
- We use quote marks instead
- Check TND to confirm if it's a quotation

## Single Quotes
- Never use `'` in phase 1
- TBTA adds them automatically for "called", "means", etc.

## Nested Quotes
```
Naomi said, ["Boaz said, ["Stay with my(Boaz's) workers"]"]
```

## Addressees
Commas separate addressee from rest:
```
"John, you(John) (imp) go to the town."
```

## Answer vs Reply
- `answer` — only when responding to a question
- `reply` — responding to a statement

```
John asked, ["Where is Mary?"]
Paul answered, ["Mary is in the town."]

John said, ["I(John) am hungry."]
Paul replied, ["I(Paul) will get food."]
```

## Common Mistakes

| Wrong | Right | Why |
|-------|-------|-----|
| No speaker | `X said, [...]` | Always need speaker |
| Bracket whole multi-sentence | `["First]. Second."` | Bracket first only |
| Single quotes | `'word'` | Never use single quotes |
| "Paul answered" (to statement) | "Paul replied" | Answer = to question |
