# Determiners (Checklist §3.1)

## The System

| Determiner | Use When | Example |
|------------|----------|---------|
| `a` / `some` | First mention | "a man came", "some men came" |
| `that` | Already mentioned | "that man went" |
| `this` | Newly contrasted or in sight | "this man was short" |
| `the` | Frame inferable or routine | "the king" (of this country) |
| ∅ (none) | Generic | "People like food" |

## First Mention
- Singular: `a man`
- Plural: `some men`
- Introduces new participant

## Routine Reference (After First Mention)
- Prefer `that` over `the`
- `that man`, `that woman`, `that town`
- After several uses, can switch to `the`

## "This" vs "That"
- `that` = already discussed, contextually near
- `this` = newly introduced contrast, or physically present

**Contrast example**:
```
A man came. That man was tall.
Then another man came. This man was short.
```

**Physical presence**:
```
"This man insults God!" (pointing)
```

## Frame Inferable
Use `the` when identity is clear from context:
- `the king` — of the country being discussed
- `the town` — where the people are
- `the land` — in the current narrative

Mark for P2 if helpful: `the king _frameInferable`

## Generic (No Article)
When talking about category, not specific instances:
- `People like [to eat]` — people in general
- `God loves all people` — generic
- `bad-B action` — sin in general

Usually plural. Singular generic is rare.

## Restrictive Modifiers
Don't use `this`/`that` with restrictive relative clauses:
- ❌ `that man [that Mary was with]`
- ✅ `the man [that Mary was with]`

Why? "That" already defines the person; you can't restrict further.

## Same Noun, Same Sentence
Write nouns the same way throughout a sentence:
- ✅ `Paul gave letters... [so that men would read letters]`
- ❌ `Paul gave letters... [so that men would read those letters]`

Why? Word order varies by language. "Those letters" might appear before "letters" in some languages.

## Common Mistakes

| Wrong | Right | Why |
|-------|-------|-----|
| "the man" (first mention) | "a man" | Use "a" for first mention |
| "the man" (after mention) | "that man" | Prefer "that" |
| "that man [who X]" | "the man [who X]" | No "that" with restrictive clause |
| "All the people" | "All of the people" | Use "all of" (unless generic) |
