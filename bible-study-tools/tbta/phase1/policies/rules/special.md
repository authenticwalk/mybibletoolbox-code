# Special Constructions (Checklist §13-24+)

## Passives (§13)
Always include agent with "by":
```
John was hit by a soldier
John was hit by a soldier _implicitActiveAgent  (if agent is implicit)
```

In He1: `John was hit <<by a soldier>>`

**Passive must convert to valid active**:
- ❌ `John went [in order to be seen by Mary]` — breaks "in order to" rule
- ✅ `John went [so that Mary could see John]`

## Rhetorical Questions (§13)
Always follow with statement version:
```
(yesrhetorical) Did God not create all things?
(statement) God created all things.
```

Markers:
- `(yesrhetorical)` — expected answer: yes
- `(norhetorical)` — expected answer: no
- `(rhetorical)` — debatable

## Imperatives (§15)
Full notation:
```
You(John) (imp) go to the town.
```
Generates: "Go to the town."

In He1: Can write as generated: `Go to the town.`

With addressee:
```
John, you(John) (imp) go to the town.
```

## Suggestive Let's (§15)
```
We(Peter) _incl go _suggestiveLets to the town
```
Generates: "Let's go to the town."

## Jussive (Third Person Imperative) (§15)
```
Peter (jussive) go to the town
```
Generates: "Let Peter go to the town."

Different from permission: `You(people) (imp) let [Peter go]`

## Pray-Hope (§15)
```
I(John) pray-hope [Peter will go to the town]
```
Generates: "May Peter go to the town."

## Ability (§2.1)
No "can" — use "able":
```
John is able [to see Mary]        (able-A: ability)
John is able-B [to eat with Mary] (able-B: circumstances allow)
```

## Causality (§8)
| Relation | Use |
|----------|-----|
| `because` | Cause (noun or clause) |
| `in-order-to` | Purpose (same agent required) |
| `so that...would` (so-C) | Purpose (different agent OK) |
| `so that...could` (so-A) | Purpose with ability |
| `so-B` | Consequence (unintended) |
| `then-D` | Consequence |

**"To" often means "in order to"**:
- ❌ `John went to see Mary`
- ✅ `John went [in order to see Mary]`

## Perfect Tense (§18)
Only use if both work:
- "John recently went" ✓
- "John previously went" ✓

If both OK → `John has gone`
If not (e.g., eternal past) → use simple past

## Conditionals (§16)
| Type | Relation | Example |
|------|----------|---------|
| Possible | if-A | `[If-A John will go] John will see Mary` |
| Unlikely | if-B | `[If-B John were to go] Mary would go` |
| Counterfactual | if-C | `[If-C John had gone] Mary would have gone` |

## Forbidden Words

| Word | Use Instead |
|------|-------------|
| can | is able [to...] |
| even | omit or rephrase |
| any | omit (use "a" in negative) |
| own | omit or use `_emphasized` |
| going to | will |

## Special Phrases

| English | TBTA |
|---------|------|
| "nation of Israel" | "nation named Israel" |
| "in prison" | "in a/the prison" |
| "all people" (specific) | "all of the people" |
| "all people" (generic) | "all people" |
| "for a while" | "for a few years" |

## Apposition (§0.40)
Not allowed except for addressees:
- ❌ `Yahweh, your God, is great`
- ✅ `Yahweh [who is your God] is great`
- ✅ `Lord, my God, you are great` (addressee OK)

## Coordinate Verbs (§30)
Very restricted — no patient or source:
- ✅ `Jesus was born and grew`
- ❌ `Peter cooked and ate the food` (has patient)

## Begin/Start/Stop/Finish (§21)
Not separate verbs — trigger aspect:
- ✅ `John started talking to Mary`
- ❌ `John started [talking to Mary]` (no bracket!)

## Titles and Paragraphs (§11)
- Title: `(title) Jesus heals a man.`
- Paragraph: `_paragraph` (phase 1) or `(paragraph)` (He1)

## Poetry (§0.53)
```
(begin-poetry)
...poetic text...
(blank-line)
...more poetry...
(end-poetry)
```
