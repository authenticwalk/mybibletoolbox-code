## Key Discoveries

### Vocabulary Patterns
1. "shield bearer" → "man [who carried a big cover for X]" (military terms)
2. "centurion" → "army leader [who was in charge of 100 soldiers]" or "officer/centurion"
3. "synagogues" → "buildings in the place [that people meet]"
4. "deceiver" → "person [who tricks people]"
5. "antichrist" → "enemy of Christ"
6. "sound doctrine" → "healthy words/teaching"
7. "temperate/self-controlled" → "control [the mind of X]"
8. "reverent" → "honor God"
9. "slanderers" → "say bad things about people"

### Structural Patterns
1. Multi-sentence quotes in epistles need splitting into separate `said` statements
2. Complex conditional + volition: "[If X], Y wanted-B [to verb]"
3. Spatial relativizers forbidden: "where" → "the place [that...]"
4. "_properName" marker for special terms like "the Way"
5. Repeated `said` for each command avoids nested quote issues

### Verb Case Frame Discoveries
1. "ask" has 6+ senses with different argument structures
2. "want-B" for same-participant clauses, "want-A" for different-participant
3. "say-A" requires bracketed content, not "words [that...]"
4. "teach" case frame varies significantly by sense
5. "belong-A" requires explicit agent in relative clause

### Grammar Patterns
1. "can" → "will be able [to...]" (forbidden word)
2. Reflexive "themselves" → repeat noun "those men/women"
3. "full reward" adjectives need nominal specification
4. "work for X" construction problematic - restructure
5. Hyphenated verbs: "stand-up", "get-up", "take-care-of"

### Genre-Specific Observations
1. **Prophetic**: Elevated vocabulary needs aggressive simplification, metaphors use `[just-like]`
2. **Gospel**: Extended dialogue manageable with proper deixis
3. **Epistle**: Dense theological language creates cascading errors, most iterations needed
4. **Narrative**: Most straightforward, cleanest linter results
5. **Acts**: "_paragraph" marker at section starts, narrative + dialogue mix
