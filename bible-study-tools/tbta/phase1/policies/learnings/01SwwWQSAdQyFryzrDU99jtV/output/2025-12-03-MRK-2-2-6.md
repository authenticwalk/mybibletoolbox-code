## Patterns Discovered

### 1. Paralysis Description
- **Reference**: `[who was not able [to move that man's legs]]`
- **V1/V3**: `[who was not able [to move that man's body]]`
- **Pattern**: Specify body part ("legs") not generic "body" → add to learnings

### 2. "Space" vs "Room"
- **Reference**: "no space" not "no room"
- **Pattern**: Use "space" for capacity, "room" for physical room → add to learnings

### 3. Verb Pairing Structure
- **Reference**: `telling/preaching` (verb pairing in L2)
- **All versions**: Used single verb
- **Pattern**: L2 verb pairings apply to verbs too, not just nouns → add to learnings

### 4. Implicit Markers
- **Reference**: Uses `_implicit` extensively (He2 format)
- **V3**: Correctly used He2 format
- **V1/V2**: Mixed or incorrect formats
- **Pattern**: Linter requires He2 underscore format even for "He1" encoding

### 5. Scribes vs Teachers
- **Reference**: "scribes" (not "teachers of the law")
- **V2**: Used "teachers" (lost specificity)
- **Pattern**: "scribes" is acceptable vocabulary → add to learnings

### 6. (implicit-situational) Marker
- **Reference v4**: Uses `(implicit-situational)` for inferred motivations
- **None**: Captured this marker
- **Pattern**: New implicit type for situational inference → add to learnings

### 7. Child vs Son
- **Reference v5**: "Child" not "Son"
- **V1**: Used "Son"
- **Pattern**: "Child" preferred for Greek τέκνον → add to learnings
